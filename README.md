# AI Phishing Detector 🛡️🤖

A lightweight text classification tool designed to identify phishing attempts using Python and `scikit-learn`.

## ✨ Features
* TF-IDF Text Vectorization.
* Logistic Regression Classifier.
* Confidence Scoring.
